# 도전! 독도골든벨 연습장

독도과거대회 예상문제 200문항으로 독도 골든벨을 준비하는 연습 사이트입니다.

- 연습하기: 세트 1·2를 순서대로/무작위로 풀고 바로 정답과 해설 확인
- 골든벨 도전: 무작위 20문제, 문제당 20초, 맞힌 개수별 인증카드
- 오답노트 / 내 기록: 각자 기기(브라우저)에 저장

## 사용한 자료
- 문항·해설: 독도과거대회 예상문제 100 (1)(2) 및 내용정리·풀이
